TopDownDemo - основная сцена игры, на которой происходит игровой процесс.
TopDownDemo3D - альтернативная версия TopDownDemo, отличия минимальные.
Main Camera - камера, имеет некоторые параметры.
Managers - компонент отвечающий за управление персонажем.
CharecterTopDown - персонаж, состоит из префаба модели, руки и тени, содержит скрипт и параметры: максимальное здоровье, неуязвимость, скорость и ускорение, максимальная скорость.
Scene - В этом объекте находятся все остальные игровые объекты.
Floor (Prefab) - пол, не имеет колизи, имеет текстуру и скрипт для исправления оффсета.
Wall (Prefab) - стена имеет коллизию, текстуру и скрипт для исправления оффсета.
Lever (Prefab) - имеет коллизию, текстуру, скрипт и параметры (ID двери позицию рычага и булевый флаг отвечающий за откат в исходное состояние после смерти)
Key (Prefab) - имеет текстуру, коллизию, скрипт и параметры, отвечающие за размер в руке, ID ключа, и скрипт для исправления отрисовки ключа (Auto Order Layer)
Door (Prefab) - имеет текстуру, коллизию, скрипт и параметры, отвечающие за скорость открывания, индекс двери, начальное состояние и звук.
Doorkey (Prefab) - аналог двери с замочной скважиной.
Shadow (Prefab) - объект тени.
