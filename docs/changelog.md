# История изменений уровня

## Изменения Сеньора
- Изменен фоновый цвет Main Camera на более атмосферный (тёмно-синий, `#00145B`) — улучшение визуального тона уровня, ощущение ночи
- Скорректирован Color у ключевых спрайтов окружения (Floor — тёмно-серый, Wall — фиолетовый, Grass1/Grass2 — тёмно-зелёный, Key — жёлтый, Lever — ярко-зелёный) — стилистическая гармонизация сцены, интерактивные предметы выделяются на тёмном фоне
- Добавлены дополнительные декоративные элементы на уровень (Grass1 (15), Grass1 (16), Grass2 (8), Grass2 (9)) — увеличение визуальной детализации
- Directional light: цвет изменён на холодный лунный (0.62, 0.72, 1), интенсивность 0.5 → 0.65, направление (50, -30, 0) → (40, 25, 0) — общий «ночной» свет, при котором тёмные стены остаются различимыми
- Point light, Point light (1)–(3): цвет изменён на тёплый «факельный» (1, 0.76, 0.48), интенсивность 1 → 1.4 — тёплые пятна света в комнатах контрастируют с холодным фоном
- Main Camera: Field of View 60 → 65 — немного расширен обзор, игроку видно больше комнаты вокруг персонажа
