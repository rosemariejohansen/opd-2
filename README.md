# TopDown Game Project

Проект создан в рамках Лабораторной работы №2 «Основы работы с Git в движке Unity». 
Игра разработана на базе шаблона Simple 2D Template (Top-Down) с модификациями уровня и настройкой автоматической сборки.

## Как запустить проект локально

1. Установите Unity Hub и версию Unity, указанную в файле ProjectSettings/ProjectVersion.txt.
2. Клонируйте репозиторий:
   git clone https://github.com/rosemariejohansen/opd-2.git
3. Откройте папку проекта через Unity Hub (кнопка Add).
4. Запустите сцену TopDownDemo, которая находится по пути: Assets/IndieMarc/TopDownDemo/Scenes.

## CI/CD и автоматическая сборка

Проект настроен на автоматическую сборку при каждом обновлении кода.

При push в ветку main GitHub Actions автоматически запускает сборку проекта под платформу StandaloneWindows64 с использованием GameCI. 
Готовые артефакты (.exe файл игры) можно скачать во вкладке Actions -> Artifacts последнего успешного запуска.
